# Workshop: Modern Web Development with Next.js & TypeScript

Taller práctico sobre desarrollo web moderno *Full-Stack* utilizando **Next.js (App Router)** y **TypeScript**. Impartido por el **Club de Programación de ESIME Zacatenco (IPN)**.

## 🎯 Objetivo del Taller

Aprender a diseñar y construir aplicaciones web escalables, tipadas y de alto rendimiento. Los estudiantes dominarán el tipado estático de TypeScript, el uso de *React Server Components*, renderizado híbrido (SSR/SSG) y la integración de backend mediante *Server Actions*.

## 📚 Módulos del Curso

* **`01-typescript-fundamentals/`**: Tipado explícito, interfaces, generics, utilidades de tipo e integración con React.
* **`02-nextjs-app-router/`**: Arquitectura del App Router, *layouts*, rutas dinámicas y diferencias entre *Server Components* y *Client Components*.
* **`03-server-actions-and-apis/`**: Manejo de estado en el servidor, validación de datos con Zod y consumo de servicios web.
